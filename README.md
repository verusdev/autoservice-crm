# АвтоСервис CRM

CRM для автосервиса: заказ-наряды, клиенты, склад запчастей, касса, дебиторка и аналитика.
Laravel 13 + SQLite, серверный рендеринг Blade, графики на собственном SVG без внешних зависимостей и без сборки фронтенда.

## Возможности

| Раздел | Что внутри |
|---|---|
| **Дашборд** | Выручка и касса за день/месяц, средний чек, дебиторка, графики выручки за 30 дней и 12 месяцев, статусы нарядов, загрузка постов, ТО-напоминания, низкие остатки |
| **Календарь** | Загрузка сервиса в режимах День / Неделя / Месяц, сетка «посты × дни», просроченные сроки, ближайшие выдачи, плановое ТО |
| **Заказ-наряды** | Приёмка → работы → запчасти → оплата → выдача. 6 статусов, авто-расчёт итогов и скидок, нормо-часы, фильтры по статусу/посту/датам/поиску |
| **Клиенты и автомобили** | Физ. и юр. лица, персональная скидка, оборот и долг в карточке; парк машин с VIN, пробегом, планом ТО по дате и километражу |
| **Склад** | Каталог с закупочной и розничной ценой, наценка, порог заказа; приход / расход / инвентаризация с историей движений; автосписание при выдаче в наряд и возврат при удалении позиции |
| **Финансы** | Касса: журнал платежей, способы оплаты, разбивка по кассирам и дням. Дебиторка: долги по клиентам, просрочки по обещанной дате |
| **Сотрудники и посты** | Роли (управляющий / мастер-приёмщик / автослесарь), ставки, выработка и маржа по мастерам; мощность и загрузка постов |
| **Отчёты** | Выручка, маржа, средний чек за неделю / месяц / квартал / год / всё время; ТО работ и запчастей, марки автомобилей, лучшие клиенты; экспорт CSV |

## Стек и решения

- **Laravel 13**, PHP 8.4, SQLite — запуск без внешней БД.
- **Blade + собственный CSS/JS** — ни Vite-сборки, ни CDN: графики (линейный, столбчатый, кольцевой) рисуются в SVG собственным кодом в `public/js/charts.js`.
- **Итоги наряда пересчитываются на сервере** из позиций работ и запчастей с учётом скидки наряда и персональной скидки клиента.
- **Склад меняется только через движения** — остаток пересчитывается транзакционно, история сохраняется.
- **Полная оплата автоматически закрывает наряд** статусом «Выдан» с датой выдачи.

## Установка

```bash
git clone https://github.com/verusdev/autoservice-crm.git
cd autoservice-crm

composer install
cp .env.example .env
php artisan key:generate

touch database/database.sqlite
php artisan migrate --seed        # миграции + демо-данные за 11 месяцев
php artisan serve
```

Открыть http://127.0.0.1:8000

**Демо-доступ:** `admin@autoservice.ru` / `password`
Другие роли: `priem@autoservice.ru`, `alexey@autoservice.ru` — тот же пароль.

## Тесты

```bash
php artisan test
```

40 feature-тестов покрывают приёмку наряда, пересчёт итогов, автосписание склада, запрет выдачи сверх остатка, возврат запчасти, оплату и частичную оплату, защиту от удаления выданного наряда, дебиторку, экспорт CSV и все режимы календаря.

## Демо-данные

Сидер создаёт 24 клиента, 33 автомобиля, 30 позиций склада, ~820 заказ-нарядов за 11 месяцев (со всеми статусами, работами, выданными запчастями и платежами), включая дебиторскую задолженность и плановые ТО. Сидёт детерминирован — данные воспроизводимы.
